# Artwork

The Sky Q artwork is from [Sky's official logo library](https://skygroup.sky/en-gb/press/assets/logos), using the white RGB Sky Q PNG. Sky and Apple marks remain the property of their respective owners; inclusion does not imply endorsement.

The SVG symbols were reused from the existing dashboard icon library (SF Symbols-style assets). These are third-party artwork, not original project artwork; check the applicable rights before redistributing a branded product. Deployments can replace these files or provide `iconImageUrl` in their own configuration.
